# Fonts offline

Be Vietnam Pro: Regular (400), Medium (500), SemiBold (600), Bold (700).
Xanh Mono: Regular (400).

Original TTF files from the Google Fonts repository:
- https://github.com/google/fonts/tree/main/ofl/bevietnampro
- https://github.com/google/fonts/tree/main/ofl/xanhmono

Both families use the SIL Open Font License 1.1; the original licenses are kept in bevietnampro-OFL.txt and xanhmono-OFL.txt. No font CDN is used at runtime. Be Vietnam Pro covers Vietnamese titles/body; Xanh Mono is reserved for short labels. IPs and measured numbers keep the system monospace stack for legibility.
